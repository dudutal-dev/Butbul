# ספר אזכרה – תהילים וקדיש

אפליקציית סלולר (PWA) להקראה בעת אזכרה בבית העלמין. עובדת גם ללא קליטה לאחר הפתיחה הראשונה.

## מה יש באפליקציה
- **דף ראשי** – תמונת שער של ההורים, כותרת והקדשה, וכניסה לעמוד של אבא ושל אמא.
- **עמוד לכל הורה** – תמונה, השם בנוסח "שם פרטי בן/בת שם האם", הקדשה אישית, ואותיות הקריאה.
- **סדר הקריאה** – לחיצה על "התחל קריאה" פותחת עמוד רציף:
  1. (אופציונלי) פרקי התהילים המקובלים על הקבר: ל"ג, ט"ז, י"ז, ע"ב, צ"א, ק"ד, ק"ל.
  2. מזמור קי"ט לפי אותיות השם: השם הפרטי, בן/בת, שם האם, ולבסוף האותיות **נ ש מ ה**.
     לדוגמה: עמרם בן רחל ← ע מ ר ם · ב ן · ר ח ל · נ ש מ ה. אותיות סופיות נקראות כאות הרגילה.
  3. קדיש יתום בנוסח ספרדי (עדות המזרח).
- **תהילים** – כל ק"נ הפרקים עם ניקוד, עם דפדוף בין פרקים.
- **קדיש** – עמוד נפרד.
- **הגדרות** – שם פרטי, בן/בת, שם האם, הקדשה ותמונה לכל הורה; תמונת שער וכותרת לדף הראשי; גודל גופן; שמירת מסך דולק.

כל הנתונים והתמונות נשמרים במכשיר בלבד (localStorage) ואינם נשלחים לשום מקום.

## התקנה על הטלפון
1. פתחו את כתובת האתר בדפדפן הטלפון (Safari באייפון, Chrome באנדרואיד).
2. אייפון: לחצו על כפתור השיתוף ← "הוסף למסך הבית". אנדרואיד: תפריט ⋮ ← "הוסף למסך הבית" / "התקנת אפליקציה".
3. האפליקציה תופיע כאייקון במסך הבית ותעבוד גם ללא קליטה.

## פרסום באינטרנט (GitHub Pages)
1. מזגו את הענף ל-`main`.
2. ב-GitHub: Settings ← Pages ← Source: **GitHub Actions**.
3. ה-workflow בקובץ `.github/workflows/pages.yml` יפרסם את האתר בכל דחיפה ל-`main`.
   הכתובת תהיה `https://<שם-המשתמש>.github.io/<שם-המאגר>/`.

## הרצה מקומית
```bash
python3 -m http.server 8000
```
ואז לפתוח `http://localhost:8000` בדפדפן.

## מבנה הקבצים
- `index.html` – כל המסכים.
- `css/style.css` – עיצוב.
- `js/app.js` – ניווט, הגדרות, תמונות וסדר הקריאה.
- `js/tehillim-data.js` – טקסט תהילים (מקור: Sefaria, "Miqra according to the Masorah", ללא טעמים).
- `js/kaddish.js` – נוסח הקדיש, שמות האותיות ורשימת הפרקים המקובלים.
- `sw.js`, `manifest.webmanifest`, `icons/` – תמיכה ב-PWA ועבודה ללא רשת.
